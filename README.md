# HangMan
A simple Hangman game developed using Java. Players try to guess the hidden word by entering letters while keeping track of their remaining attempts.

## Features

- Four word categories:
  - Movie Title
  - Fictional Character
  - Places in Malaysia
  - Proverbs
- Random word or phrase selection
- Letter guessing
- Whole phrase guessing
- Six attempts for each game
- Displays the remaining attempts
- Reveals the correct phrase when the player loses

## Technologies Used

- Java

## How to Play

1. Run the `Hangman.java` file.
2. Choose one of the four available categories.
3. The game randomly selects a word or phrase from the chosen category.
4. Choose whether to:
   - Guess a letter
   - Guess the whole phrase
5. Continue guessing until you correctly identify the phrase or run out of attempts.
6. You have a maximum of six incorrect attempts.
